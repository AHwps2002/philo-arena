# 哲学竞技场

一个纯前端的小游戏：**输入几个名字，看他们在淘汰赛里用哲学招式互相拆解。**

玩法参考了「名字竞技场」的核心设定——名字本身就是全部随机性的来源。同样的名字，永远打出同样的结果；改换输入顺序，结果也不变。

## 怎么玩

双击 `index.html`，用浏览器打开即可。不需要安装、不需要服务器、不联网。

1. 在左边输入名字，每行一个（2–16 位）；
2. 点「开始辩论」；
3. 之后什么都不用做——比赛会自动一场一场打完。

## 规则

每个名字会被哈希成四项属性（38–92）：

| 属性 | 作用 |
| --- | --- |
| 逻辑 | 既是攻击属性，也是防御：数值越高，受到的伤害越少 |
| 修辞 | 修辞学派招式的威力来源 |
| 洞见 | 决定先手；洞见高的人先开口 |
| 意志 | 决定血量上限（120 + 意志 × 0.8） |

**学派** = 四项里最高的那一项，决定你能用哪四招：

- 逻辑学派：三段论、归谬法、奥卡姆剃刀、说谎者悖论
- 修辞学派：苏格拉底反诘、洞穴寓言、灵魂助产术、修辞术
- 洞见学派：我思故我在、现象学悬置、语言游戏、电车难题
- 意志学派：权力意志、上帝已死、存在先于本质、绝对精神

伤害 = 招式威力 + 攻击属性 × 0.25 − 对方逻辑 × 0.12，再乘 0.85–1.15 的浮动；12% 概率暴击（×1.55）。40 回合内没分出胜负，就比剩余血量比例。

## 确定性是怎么保证的

这是整个项目的技术核心：

1. `xmur3` 把名字哈希成 32 位种子；
2. `mulberry32` 用种子生成随机数序列——同样的种子必然产出同样的序列；
3. 选手属性、招式选择、伤害浮动、暴击，全部来自这个序列；
4. 对阵表按**名字哈希排序**后再两两配对，所以输入顺序不影响任何结果；
5. 单场对战的种子 = 双方名字排序后拼接，与谁先谁后无关。

页面上那个 `#402B9A21` 就是全部名字的联合种子，可以当作“这一局的编号”用来分享。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式（深夜书房配色） |
| `engine.js` | 纯逻辑：哈希、属性、对战、赛程。不碰 DOM，可在 Node 里直接测 |
| `game.js` | 界面：渲染对阵图、播放战报、血条动画 |

`engine.js` 末尾有一行 `module.exports`，所以它既能被浏览器当普通脚本加载，也能被 Node `require` 出来跑测试（`file://` 下 ES module 会被 CORS 拦，所以这里刻意用了普通脚本）。
