# 哲学竞技场

一个纯前端的小游戏：**输入几个名字，看他们在淘汰赛里用哲学招式互相拆解。**

玩法参考了「名字竞技场」的核心设定——名字本身就是全部随机性的来源。同样的名字，永远打出同样的结果；改换输入顺序，结果也不变。

## 怎么玩

双击 `index.html`，用浏览器打开即可。不需要安装、不需要服务器、不联网。

1. 在左边输入名字，每行一个（2–16 位）；
2. 点「开始辩论」；
3. 之后什么都不用做——比赛会自动一场一场打完。

## 规则

每个名字会被哈希成四项属性（38–92）：

| 属性 | 作用 |
| --- | --- |
| 逻辑 | 既是攻击属性，也是防御：数值越高，受到的伤害越少 |
| 修辞 | 修辞学派招式的威力来源 |
| 洞见 | 决定先手；洞见高的人先开口 |
| 意志 | 决定血量上限（120 + 意志 × 0.8） |

**学派** = 四项里最高的那一项，决定你能用哪四招：

- 逻辑学派：三段论、归谬法、奥卡姆剃刀、说谎者悖论
- 修辞学派：苏格拉底反诘、洞穴寓言、灵魂助产术、修辞术
- 洞见学派：我思故我在、现象学悬置、语言游戏、电车难题
- 意志学派：权力意志、上帝已死、存在先于本质、绝对精神

伤害 = 招式威力 + 攻击属性 × 0.25 − 对方逻辑 × 0.12，再乘 0.85–1.15 的浮动；12% 概率暴击（×1.55）。40 回合内没分出胜负，就比剩余血量比例。

## 确定性是怎么保证的

这是整个项目的技术核心：

1. `xmur3` 把名字哈希成 32 位种子；
2. `mulberry32` 用种子生成随机数序列——同样的种子必然产出同样的序列；
3. 选手属性、招式选择、伤害浮动、暴击，全部来自这个序列；
4. 对阵表按**名字哈希排序**后再两两配对，所以输入顺序不影响任何结果；
5. 单场对战的种子 = 双方名字排序后拼接，与谁先谁后无关。

页面上那个 `#402B9A21` 就是全部名字的联合种子，可以当作“这一局的编号”用来分享。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式（深夜书房配色） |
| `engine.js` | 纯逻辑：哈希、属性、对战、赛程。不碰 DOM，可在 Node 里直接测 |
| `game.js` | 界面：渲染对阵图、播放战报、血条动画 |

`engine.js` 末尾有一行 `module.exports`，所以它既能被浏览器当普通脚本加载，也能被 Node `require` 出来跑测试（`file://` 下 ES module 会被 CORS 拦，所以这里刻意用了普通脚本）。

## 想改的话

- **加人**：`game.js` 顶部的 `PRESETS` 和 `POOL`；
- **加招式**：`engine.js` 里的 `SCHOOLS`，每个学派一个 `moves` 数组；
- **调节奏**：`game.js` 的 `sleep(300)` 那几处，或 `state.pace`；
- **改配比**：`engine.js` 里 `38 + Math.floor(rng() * 55)`（属性范围）和 `120 + stats.will * 0.8`（血量）。

# 名录与技能（第二版）

原来的规则是"名字哈希出属性"——公平，但苏格拉底和路人甲没有区别。现在加了一层**手工卡**：34 位哲学家的属性、学派、专属招式与被动都按其历史评价设定。

## 四项属性怎么对应人物

| 属性 | 在游戏里是 | 历史上对应 |
| --- | --- | --- |
| 逻辑 | 攻击 + 防御（减伤） | 体系构造、论证严密 |
| 修辞 | 攻击 | 对话、说服、反诘 |
| 洞见 | 先手 + 攻击 | 直观、洞察、范式转换 |
| 意志 | 血量 + 气势 | 生命力、行动、不肯让步 |

举例：亚里士多德逻辑 92（体系最严），弗雷格 93 但修辞只有 45（几乎不会说服人），尼采意志 95（HP 最高）而逻辑只有 60（论证薄弱），第欧根尼修辞 90 但逻辑 55。

## 六种被动

| 被动 | 效果 | 谁有 |
| --- | --- | --- |
| 反诘 | 受击后有机会反弹四成 | 苏格拉底、黑格尔、萨特、休谟 |
| 深渊 | 血越少打得越重 | 尼采、加缪、叔本华 |
| 不动 | 第一次受击减免大半 | 康德、柏拉图、亚里士多德 |
| 扬弃 / 实践 | 击中时吸血（有上限） | 黑格尔（已改反击）、马克思（已改反击） |
| 沉默 | 有机会完全闪避 | 维特根斯坦、海德格尔、芝诺 |
| 剖析 | 暴击率更高 | 罗素、弗雷格、卡尔纳普 |

## 专属招式

每人一招，用其思想的核心概念命名：苏格拉底「反诘到底」、柏拉图「洞穴之光」、康德「绝对命令」、黑格尔「绝对精神」、维特根斯坦「保持沉默」、尼采「权力意志」……

其余三招是"无主"的通用招式（反例、定义、类比、追问、直觉、沉默、坚持、挑衅、让步、举例、反问、凝视），避免让尼采使出"绝对精神"这种张冠李戴。

## 平衡怎么保证的

`roster-test` 跑了 500 场随机八人赛，统计冠军分布：

- 单一角色最高 11.6%（均匀分布约 12.5% / 34 人 × 8 人局）；
- 没有任何角色超过 35%；
- 同时校验：学派 = 最高属性、专属招式在招式池内、HP 不为负、每场以胜者结束、打乱输入顺序冠军不变。

调参过程中改过三轮：黑格尔的吸血过强（40.6%），马克思均衡高属性过强（37.8%），意志流靠"血量 + 怒气"双重收益过强（25.8%）。最终把吸血加上限、逻辑的减伤权重从 0.12 降到 0.09、血量公式的意志系数从 0.8 降到 0.6。

## 未知名字

不在名录里的名字仍然走原来的哈希生成——规则"名字决定结局"没有被破坏，只是名人有了自己的性格。

## 名言与出处

冠军卡上的那句话不再是随手摘的。34 位哲学家每人配了一条**可归属**的语录，并在下方标出出处：

- 康德 ——《实践理性批判》
- 尼采 ——《善恶的彼岸》
- 马克思 ——《关于费尔巴哈的提纲》
- 维特根斯坦 ——《逻辑哲学论》

有两处原本归属不稳，已经换掉：

- 柏拉图原用"哲学始于惊奇"（常被同时安给亚里士多德），改为《理想国》518c 关于"教育是转向"的那句；
- 罗素原用"参差多态乃是幸福的本源"（中文世界流传广，但原文出处难考），改为《自传》开篇"三种激情"。

苏格拉底、第欧根尼、赫拉克利特、毕达哥拉斯等人的话属于**古代转述**，出处标为《申辩篇》《名哲言行录》或"残篇"，不假装是本人手笔。

**不在名录里的名字**获胜时，用的是一组无主格的句子（"凡被说出的，都可能被反驳"），不借用任何名人的话——否则会出现"张三说：我唯一知道的，就是我一无所知"这种张冠李戴。

## 被动为什么是这一个

被动不是随便贴的标签，而是把各人的**方法**翻译成一条战斗规则。每个被动都带一句理由，鼠标悬停或看冠军卡都能读到。

| 机制 | 哲学依据 | 谁 |
| --- | --- | --- |
| 反诘（受击反弹） | 诘问法：让对方在回答中推翻自己 | 苏格拉底 |
| 扬弃（受击反弹） | 否定之否定：把攻击纳入自身再返回 | 黑格尔 |
| 先验（首击减免） | 用先天形式把经验条件化 | 康德 |
| 理念（首击减免） | 理念不受现象侵蚀 | 柏拉图 |
| 不动（首击减免） | 存在者不动，攻击无处着力 | 巴门尼德 |
| 不动心（首击减免） | 理解必然性，情绪不再扰动 | 斯宾诺莎 |
| 看破（首击减免） | 看透欲望的虚幻 | 叔本华 |
| 整体（首击减免） | 信念之网，局部攻击不致命 | 蒯因 |
| 悬置（闪避） | 把存在判断括起来 | 胡塞尔 |
| 沉默（闪避） | 问题被消解，攻击失去着力点 | 维特根斯坦 |
| 流变（闪避） | 万物流变，抓不住 | 赫拉克利特 |
| 悖论（闪避） | 永远差那一点 | 芝诺 |
| 无规定（闪避） | 存在先于本质，规定落空 | 萨特 |
| 权力意志（越挫越强） | 受挫正是意志增长的条件 | 尼采 |
| 反抗（越挫越强） | 反抗在压迫最强时显出力量 | 加缪 |
| 行动（越挫越强） | 行动本身就是存在的证明 | 费希特 |
| 分析 / 严格 / 句法（暴击） | 拆到原子、分清指称、句法检验 | 罗素、弗雷格、卡尔纳普 |
| 揭露（暴击） | 揭穿「永恒女性」的神话 | 波伏娃 |
| 跳跃（暴击） | 信仰之跃跳过论证 | 克尔凯郭尔 |

改过的地方（原来与史实相悖）：

- 叔本华原为「越挫越勇」，与悲观主义相反，改为「看破」减伤；
- 克尔凯郭尔原为「越挫越勇」，改为「跳跃」暴击——信仰之跃是跳过论证，不是越打越强；
- 萨特原为「反诘」，改为「无规定」闪避——存在先于本质，任何规定都落空；
- 休谟原为「反诘」，改为「怀疑」闪避——悬置因果，攻击无从确立。

## 一个已知的抽象

学派是按最高属性分的四类（逻辑 / 修辞 / 洞见 / 意志），不是历史阵营。苏格拉底被归入「修辞学派」，是因为他的方法就是靠对话进行——尽管他本人反对智者的修辞术。这是游戏分类与思想史之间无法完全对齐的地方，写在这里备查。

# 赛前名录、逐轮揭晓与历史画像

## 赛前名录

打开页面先看到的是**参赛者名录**，不是空对阵图。每张卡有头像、姓名、学派，点一下直接打开人物卡——不用等比赛开始。

在左侧文本框里改名字，名录会实时刷新（去抖 180ms）。

## 逐轮揭晓

对阵图不再一次性画完。现在的节奏是：

1. 只显示本轮的对阵；
2. 本轮所有比赛打完后，才插入下一轮的列；
3. 冠军列从始至终是个「？」，直到决赛结束。

实现上，引擎仍然一次算完全部结果（保证确定性），但界面每次只渲染 `rounds[i]`，`i` 由播放循环推进。所以"算完了"和"让你看见"是分开的。

## 历史画像

人物卡和名录优先使用 `portraits/` 里的真实画像：

```
portraits/苏格拉底.jpg
portraits/尼采.png
```

找不到就自动退回内置的 SVG 肖像（按 jpg → png → webp 依次尝试）。所以你可以先只有几个人有图，剩下的继续用几何肖像，不会出现破图。

`fetch-portraits.py` 走 Bing 图片搜索（Wikimedia 在本机被墙时不可用），会按名字抓取第一张可用结果。**注意：**

- 沙箱里访问 Wikimedia 会连接超时，这个脚本只能在你自己联网的机器上跑；
- 自动取搜索第一条，可能抓到雕像照片、书封或他人画像，**必须逐张核对**；
- 19 世纪以前的画作一般是公有领域；波伏娃、罗素、蒯因等人的摄影肖像可能仍有版权，使用前确认。

删掉不对的图片，界面会自动退回 SVG 肖像。

## 关于水印

**不去水印。** 水印通常是权利声明，抹掉它不会让图片变得可用，只会让"这张图到底能不能用"更说不清。

脚本的做法是**避开**：Alamy、Getty、Shutterstock、iStock、Dreamstime、123RF、Depositphotos、Freepik、FineArtAmerica、PaintingValley 等图库站一律跳过。抓完后再人工看一遍——34 张里查出 4 张错的（第欧根尼抓到课件文字页、卡尔纳普和戴维森抓到书封、巴门尼德抓到双人像），全部重抓或换图。

如果以后某张图带水印，正确做法是删掉它（界面会自动退回 SVG 肖像），而不是修图。

## 版权提醒

- 古代雕像、19 世纪以前的油画和版画：公有领域，可放心用；
- **20 世纪人物的摄影肖像**（波伏娃、罗素、蒯因、克里普克、列维纳斯、加缪、萨特、海德格尔、胡塞尔、维特根斯坦、雅斯贝尔斯、戴维森、刘易斯、卡尔纳普）：可能仍在版权保护期内。自己本地玩没问题，**公开发布前建议替换成公有领域的画像或取得授权**。

每张图的来源 URL 记录在 `portraits/sources.json` 里，便于追溯。

# 学派按思想史归类

原先「学派 = 最高属性」，于是苏格拉底因为修辞分最高被归进修辞学派——而他一生最反对的就是智者的修辞术。这是把统计结果当成了历史身份。

现在学派是**手写的**，按师承与方法归类；属性只表示个人强弱，两者可以不一致。

| 学派 | 依据 | 成员 |
| --- | --- | --- |
| **逻辑** | 辩证法、逻辑学、系统建构 | 苏格拉底、亚里士多德、康德、黑格尔、马克思、巴门尼德、芝诺、斯宾诺莎、罗素、弗雷格、卡尔纳普、蒯因、戴维森、克里普克、刘易斯 |
| **修辞** | 以对话、叙事、公开表达为方法 | 柏拉图、第欧根尼、克尔凯郭尔、波伏娃 |
| **洞见** | 现象学、存在论、直观 | 维特根斯坦、海德格尔、赫拉克利特、休谟、毕达哥拉斯、谢林、胡塞尔、梅洛-庞蒂、列维纳斯 |
| **意志** | 生命哲学、存在主义 | 尼采、加缪、萨特、叔本华、费希特、雅斯贝尔斯 |

几个刻意的"不一致"：

- **苏格拉底**：修辞 88 最高，但归入逻辑学派——诘问法是论证，不是说服；
- **柏拉图**：洞见 90 最高，但归入修辞学派——他留下的全部是对话；
- **克尔凯郭尔**：归入修辞——假名写作与"间接传达"是他的方法；
- **马克思**：归入逻辑——辩证法是他的骨架，而不是意志。

学派只影响**通用招式的池子**（逻辑系拿反例/定义，修辞系拿类比/追问，洞见系拿直觉/沉默，意志系拿坚持/挑衅）；专属招式、属性、被动都不受它影响。

分布是 15 / 4 / 9 / 6，修辞学派偏少，但这是按史实归类的真实结果，没有为了平均而硬塞。

# 标签与评价

学派是四选一的框，硬把每个人塞进去，总会失真。所以界面上不再显示学派，改成两层：

**短标签（epithet）**——2–4 个字，用于对阵表和名录：诘问者、锤子、界碑、木桶、飞矢、第二性、可能世界……

**评价（evaluation）**——一句话，用于人物卡：

- 苏格拉底：「以诘问取代说教，逼对手在回答里推翻自己；一生不写一字，却成了哲学的起点。」
- 康德：「给理性划界：既不许它越界，也不许它退场。此后的哲学都得先过这道关。」
- 马克思：「不只解释世界，还要改变世界；他的概念至今仍是最锋利的批判工具。」
- 维特根斯坦：「前期给语言划界，后期取消界；留下的不是理论，是一种疗法。」

评价是**带判断的**，不是生平简介——它会说某人"悲观得彻底，也因此看得清楚"，也会说芝诺"结论错了，问题却一直有效"。

## 学派去哪了

还在，但退回成内部字段：它只决定通用招式的池子（逻辑系拿反例/定义，修辞系拿类比/追问……）。界面上不显示，也不影响属性、专属招式或被动。

这样"学派"不再冒充身份，评价也不必迁就四分类。

## 三种粒度

同一个人的评价，按展示空间分三档，并保持各处的用词一致：

| 层级 | 用在哪 | 例子（苏格拉底） |
| --- | --- | --- |
| `epithet`（2–4 字） | **名录缩略卡、对阵表、战报** | 诘问者 |
| `shortEval`（5–7 字） | 名录卡的悬停提示 | 诘问逼人认输 |
| `evaluation`（一句话） | 人物卡正文 | 以诘问取代说教，逼对手在回答里推翻自己；一生不写一字，却成了哲学的起点。 |

统一用称号的好处是：战报里写「康德」（界碑），对阵表里也是「界碑」，名录里还是「界碑」——同一个人的标签不会在两处变成两句话。想多看一点，把鼠标停在名录卡上，会显示 `shortEval`；点开人物卡才是完整评价。

# 武力

哲学家吵不过的时候，也可以动手。

每场比赛每人**最多一次**：当自己的立场降到 32% 以下，有约 50%–70% 的概率（随武力值上升）不再讲道理，直接造成 `10 + 武力 × 0.3` 点伤害。这一击：

- **无视**「不动」的减伤和「沉默」的闪避；
- 自己掉 5 点——失态也是有代价的；
- 只发生一次，之后回到论辩。
